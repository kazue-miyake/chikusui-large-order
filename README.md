# 大口注文 製造指示書作成ツール

大口注文用の製造指示書を作成し、A4縦1枚で印刷またはPDF保存するための単体HTMLアプリです。

## 公開方法

GitHub Pagesで公開する場合は、このフォルダの中身をリポジトリのルートに置きます。

1. GitHubで新しいリポジトリを作成します。
2. `index.html`、`.nojekyll`、この `README.md` をリポジトリ直下にアップロードします。
3. Settings -> Pages を開きます。
4. Source を `Deploy from a branch` にします。
5. Branch を `main`、Folder を `/root` にして保存します。
6. 表示された公開URLをスマホで開いて確認します。

## スマホ確認項目

- 画面が横スクロールなしで開ける
- 入力フォームに文字を入れられる
- 写真を選択してプレビューに表示できる
- 保存後、同じスマホの同じブラウザで再表示できる
- 印刷/PDFボタンからスマホ側の印刷または共有導線に進める

## 注意

データ保存はブラウザの `localStorage` です。PCとスマホ間では注文データは共有されません。
